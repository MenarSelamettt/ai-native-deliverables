# Day 5 Starter — Would You Ship This?

Week 4 Day 5 release-confidence review starter. The Day 4 product behavior is complete; Day 5 focuses on evaluating and improving the evidence used to make a release decision.

## Start the app

```bash
npm ci
npm run dev
```

## Available commands

- `npm run dev` — start the local development server
- `npm run typecheck` — check TypeScript
- `npm run lint` — check code quality
- `npm test` — run the focused component and integration suite
- `npm run build` — create a production build
- `npm run preview` — serve the production build locally
- `npm run e2e` — run the Chromium release journey
- `npm run e2e:install` — install Chromium locally if it is not already available

Mock API mode remains enabled by default. All application behavior and architecture are inherited from the finalized Day 4 reference.

The cohort platform contains the learner instructions and exit criteria. Record the Day 5 evidence assessment and release decision in `RELEASE_REVIEW.md`.
