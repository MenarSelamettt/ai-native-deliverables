# Personal Spending Dashboard

Day 1 starter project for **React Foundations: Model the UI**.

## Start the app

```bash
npm ci
npm run dev
```

## Available commands

- `npm run dev` — start the local development server
- `npm run typecheck` — check TypeScript
- `npm run lint` — check code quality
- `npm test` — run the smoke test
- `npm run build` — create a production build

Learner instructions and exit criteria are provided in the cohort platform.
